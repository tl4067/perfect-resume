# JD matching and resume generation

1. JD decomposition

## JD decomposition

Extract the role's core outcome, hard requirements, recurring responsibilities, tools, domain knowledge, behavioral expectations, and optional qualifications. Normalize synonyms without inventing equivalence between materially different tools or industries.

## Match levels

Produce this table before drafting:

| JD requirement | Match | Source IDs | Evidence | Action |
|---|---|---|---|---|
| Requirement text | Strong / Medium / Weak / Gap | IDs or none | Specific fact | Emphasize / Support / Validate / Omit |

- Strong: direct, verified, and contextually similar evidence.
- Medium: verified capability in a different context with a defensible transfer.
- Weak: coursework, theory, limited exposure, or indirect evidence.
- Gap: no credible supporting evidence.

Hard requirements with gaps must remain visible in the report. Do not hide them by keyword stuffing.

## Gap validation

For a material gap, output:

1. Minimum learning objective
2. Small practical task resembling the target context
3. Completion criteria
4. Evidence to save
5. Three to five interview questions

Do not label a gap as “learning” unless the user has started. Do not put a planned validation task in work or project experience.

## Resume assembly

Choose the smallest set of evidence that supports the role. Use strong matches first, then medium matches. Include weak matches only when they help explain credible potential. Omit unsupported keywords.

Each bullet must answer:

- What problem or goal existed?
- What did the user personally do?
- What changed or was delivered?
- How was it measured or verified?

The final wording does not need to expose IDs, but maintain an accompanying internal mapping from every material claim to its source ID.

## Final audit

Reject or revise a sentence when:

- It cannot be traced to a source ID.
- It adds a common technical step not present in the source.
- It changes participation level.
- It turns an estimate, application, plan, or ongoing task into a completed result.
- It omits the baseline or operating condition needed to interpret a number.
- It uses personal data not approved for the current resume.
