# 个人经历库（通用空白模板）

> 用途：保存可追溯的个人经历和能力证据，供岗位分析与求职简历使用。用户数据只存放在自己的工作区；本模板不替代 perfect-resume 的执行规则。

## 使用说明

- 只在一次提交中更新来源叙述、主记录、直接受影响的索引和一条维护日志。
- 记录是否可保存与是否足以写简历要点分别判断。
- 可直接陈述的事实保留为用户事实；AI压缩或改写的句子标为 AI整理-待确认，除非只是忠实改写。
- 旧版详细记录原位保留。普通新增或更正不迁移、重排或规范化全库。
- 能力索引是检索辅助，不是自动提问队列。

## 0.1 状态标签

信息状态：

- 用户已确认：用户直接陈述或确认。
- 资料来源-待本人复核：来自旧简历、证书、作品等，尚未核对。
- AI整理-待确认：AI形成的可能改变含义的表述。
- 待补充：缺口会阻断安全的简历表述。
- 可选待补充：有帮助但不阻断当前任务的增强项。
- 存在冲突：互斥陈述尚未解决。

能力状态：

- 用户自述：直接说明掌握或使用，不强制绑定项目。
- 已验证：有具体经历、产出、结果或验证过程支持；不等于第三方核验。
- 可迁移：相邻场景证据支持，尚未在目标场景直接使用。
- 待补齐：当前证据不足。

简历充分性独立记录为 足够 或 不足（原因）。不要用单一状态覆盖不同事实组。
